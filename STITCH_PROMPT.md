# Google Stitch UI direction

Build ExamPrep Planner as a calm Zen productivity dashboard for competitive-exam aspirants. Use white/off-white surfaces, deep forest green accents, muted sage, generous whitespace, rounded cards, subtle borders, soft shadows, restrained iconography and clear typography. Avoid gradients, loud colors, gamification and visual clutter. Prioritize a focused desktop sidebar and a compact mobile navigation. The dashboard should make syllabus progress, today's study plan and next action immediately obvious.
